# UWB 3D upgrade inspection

This file records the pre-upgrade baseline. The resulting implementation and qualification status are in [UWB3D_TRACKING.md](UWB3D_TRACKING.md). The new candidate adds explicit experimental activation, extended PHY, delayed TX, a sparse BP MCU scheduler and UART aggregation; it does not qualify the proposed3ms schedule. Baseline PHY/frame statements below describe deployed1.0.13, not the candidate.

The existing application entry is `Control_Center.cmd` → `tools/control_app.py`: Tkinter on the UI thread, one asyncio loop on a background thread, BLE/UART `Session` transports, JSON configuration and session logs. Existing OTA, provisioning, individual diagnostics, single-anchor ranges, surveyed four-anchor positioning and sparse cooperative relative tracking must remain available.

Firmware is Zephyr/PlatformIO (`platformio.ini`, `zephyr/CMakeLists.txt`, `src/main.c`). The checked-in DW3000 driver exposes delayed TX and actual TX/RX timestamps. `src/radio.c` currently uses channel 5, 64-symbol preamble, standard PHR, 6.8 Mbps, STS off and a 64-byte application frame limit. `src/ranging.c` implements four-message DS-TWR with actual timestamps, a 2 ms response delay and synchronous polling. The main loop also services IMU and console. Therefore a 3 ms deterministic broadcast slot is NOT supported by the existing execution architecture. The proposed 128-symbol preamble is not the current deployed PHY.

Hardware sources: `HARDWARE.md`, README, `docs/INSPECTION.md`, native-design-derived schematic evidence in `tmp/inspection`, module/IMU datasheets under `Cyborg_Main/DOC`, board overlays, vendor driver headers and current tests. The PCB is nRF52833/DW3110 DWM3001C with BNO085 (not proven BNO088), UART 115200 8N1 on TX P0.20/RX P0.21, and BLE control/SMP. No physical TCP/UDP gateway, battery ADC or world-frame acceleration telemetry is established. ST-Link is SWD, not the UART adapter. LED3 is the role LED; LED2 is charger controlled. UV/PWM outputs must remain inactive.

Implementation modules: `tools/uwb3d_protocol.py` (binary framing, timestamps and experimental BP contract), `uwb3d_core.py` (registry, matrix, solver/filter and configuration), `uwb3d_runtime.py` (bounded ingestion, simulation, replay, logging), `uwb3d_view.py` (integrated Tk 3D view and dashboard). The existing cooperative page is retained inside UWB 3D Tracking, not replaced with simulated data. Firmware integration adds portable protocol/timestamp helpers and explicit capabilities; unqualified broadcast activation must fail rather than silently use incompatible PHY/scheduling.

Verification: existing portable C/Python test runner and PlatformIO build; new deterministic protocol, geometry and pipeline tests; offline 30-node stress measurements and actual GUI screenshots. Six coplanar bench nodes cannot validate 30-node noncoplanar radio performance. Existing six-board measurements remain historical evidence only.
